# PRD: 반려동물 식품/용품 관리

> 작성일: 2026-04-12
> 상태: 초안

## 문제 정의

반려동물 용품(쳇바퀴, 은신처 등)을 언제 소독했는지 기억하기 어렵고, 식품류의 유통기한을 별도로 관리하지 않아 유통기한이 지난 식품을 버리는 일이 발생하고 있다. 이를 한곳에서 등록·추적할 수 있는 기능이 필요하다.

## 사용자 시나리오

1. **식품 등록**: 사용자가 새로운 식품(밥, 간식, 건초 등)을 구매하면 카테고리·이름·유통기한을 입력해 등록한다. 유통기한이 가까워지면 인지할 수 있다.
2. **청소/소독 기록**: 쳇바퀴 소독, 모래존 청소 등 케어를 완료한 뒤 해당 항목을 선택해 오늘 날짜로 기록한다.
3. **캘린더 확인**: 캘린더 뷰에서 날짜별로 어떤 청소·소독을 했는지 한눈에 파악한다.

## 기능 요구사항

### A. 식품 카테고리 관리
- [ ] 사용자가 카테고리 직접 추가 / 편집 / 삭제 가능 (기본 제공 없음)

### B. 식품 등록 및 유통기한 관리
- [ ] 식품 등록 시 카테고리 선택, 이름, 유통기한 입력
- [ ] 등록된 식품 목록 조회 가능
- [ ] 유통기한 임박/만료 상태 표시 (D-14: 1차 경고, D-7: 2차 경고)

### C. 청소/소독 종류 관리
- [ ] 사용자가 청소 종류 직접 추가 / 편집 / 삭제 가능 (기본 제공 없음)

### D. 청소/소독 기록 및 캘린더
- [ ] 특정 날짜에 수행한 청소 종류를 기록
- [ ] 캘린더 뷰에서 날짜별 청소 기록 표시
- [ ] 마지막으로 각 청소를 수행한 날짜 확인 가능

## 범위 밖 (Out of Scope)

- 알림/푸시 기능 (유통기한 임박 알림 등) — 추후 검토
- 여러 반려동물 프로필 분리 관리 — 추후 검토
- 식품 구매 이력 / 소비량 통계

## 완료 기준 (Definition of Done)

- [ ] A: 식품 카테고리 추가·편집·삭제 동작
- [ ] B: 식품 등록 및 유통기한 상태 표시 동작
- [ ] C: 청소 종류 추가·편집·삭제 동작
- [ ] D: 청소 기록 저장 및 캘린더 표시 동작

## 관련 파일

- 없음 (신규 기능)

## 기술 결정 사항

- **데이터 저장**: 1차 로컬 저장 (기기 내) → 추후 Supabase 서버 동기화 확장
- **데이터 레이어 설계**: `services/` 내에 저장소 인터페이스를 추상화하여, 로컬 구현체 → Supabase 구현체로 교체 가능하게 설계 (비즈니스 로직 변경 최소화)
