---

## Your task

PRD 작성을 위한 질문 출력 후 답변 대기. 답변하기 어려운 항목은 "모름" 또는 "-"로 생략 가능.

---

**1. 기능 이름은?**
(예: 장바구니 수량 변경, 소셜 로그인)

**2. 어떤 문제를 해결하나요?**
(예: 현재 수량 변경이 안 돼서 삭제 후 재추가해야 함)

**3. 주요 사용 시나리오는?**
(예: 사용자가 장바구니에서 +/- 버튼을 눌러 수량 조절)

**4. 핵심 기능 요구사항은?** (되어야 하는 것들)
(예: 수량 변경 즉시 UI 반영, 0이 되면 자동 삭제)

**5. 이번 범위에서 제외할 것은?**
(예: 재고 초과 방지, 최소 주문 수량 검증)

**6. 완료 기준은?** (이게 되면 "다 됐다"고 할 수 있는 것)
(예: 수량 변경 + 자동 삭제 + 에러 케이스 모두 동작)

**7. 관련된 기존 파일이나 컴포넌트가 있나요?** (없으면 "-")
(예: `src/components/CartItem.tsx`, `src/stores/cartStore.ts`)

---

## 답변 수신 후

### 파일 저장

- `docs/` 폴더 미존재 시 생성 (`mkdir -p docs`)
- 파일명: `docs/prd-[기능명-kebab-case].md`
  - 한국어 기능명 → 영어 의미 보존하여 kebab-case 변환
  - 예: "장바구니 수량 변경" → `docs/prd-cart-quantity.md`

### PRD 파일 형식

```markdown
# PRD: [기능 이름]

> 작성일: [오늘 날짜]
> 상태: 초안

## 문제 정의
[어떤 문제를 해결하는지]

## 사용자 시나리오
[주요 사용 흐름 1~3개]

## 기능 요구사항
- [ ] [요구사항 1]
- [ ] [요구사항 2]

## 범위 밖 (Out of Scope)
- [제외 항목]

## 완료 기준 (Definition of Done)
- [ ] [기준 1]
- [ ] [기준 2]

## 관련 파일
- [파일 경로 또는 "-"]

## 미결 사항
<!-- 불명확한 부분만 작성. 없으면 섹션 삭제 -->
- [ ] TODO: [확인 필요한 사항]
```

### 완료 안내

```
✅ PRD 저장 완료: docs/prd-[파일명].md

다음 단계:
- 내용 검토 후 필요 시 직접 수정
- 구현 준비 완료 시 /plan 실행
```
